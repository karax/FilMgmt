# Canonical material catalog coverage

The Materials seed is a technical classification catalog, not a list of
manufacturer SKUs. Manufacturer-specific product names belong in
`Spool.product_name`; the material record identifies the reusable polymer,
blend, reinforcement, hardness, or support profile.

The catalog was designed to classify the publicly available product families
of these European-market brands: Prusament, Polymaker, eSUN, SUNLU, Bambu Lab,
Fiberlogy, Fillamentum, FormFutura, Extrudr, Spectrum Filaments, colorFabb,
AzureFilm, Devil Design, ROSA3D, Recreus, add:north, Filament-PM, Eryone,
3DJake, and Nobufil.

It intentionally does not create separate materials for colours, spool sizes,
refills, packaging, rainbow/gradient effects, or commercial product labels.
Defaults for temperature and density are omitted unless a generic technical
value is defensible; manufacturer data sheets remain the source of truth for
specific products.
